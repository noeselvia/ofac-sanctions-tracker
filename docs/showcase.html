    How it’s built

    From public notices
    to this page. Daily.

    An automated pipeline with no manual steps. The same model feeds a Power BI report.

    01

    Collect

    Scrapes every OFAC list-update notice and downloads the SDN, ALT and ADD files and the UN XML.

    Python · requests
    02

    Parse

    Turns free-text notices into one record per entry: action, type, country, programs, aliases, links.

    regex · unit tests
    03

    Model

    Loads a star schema and diffs daily snapshots by entity number to detect changes on its own.

    SQLite · SQL views
    04

    Publish

    Rebuilds Power BI exports and these pages, then commits them every morning at 7:17.
